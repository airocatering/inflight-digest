# Inflight Digest

Отраслевое издание про бортпитание, развлечения на борту и обслуживание пассажиров.
Статический сайт на GitHub Pages, материалы собираются из RSS и публикуются
только после ручного одобрения редактором.

## Как это работает

```
RSS-ленты  →  queue/*.md  →  вы меняете status  →  posts/*.md  →  HTML на сайте
   робот         черновики        вручную            архив          автоматически
```

1. Раз в час GitHub Actions запускает `scripts/fetch_feeds.py`. Он читает ленты
   из `scripts/feeds.json`, отбрасывает то, что уже видел, и кладёт новое в
   `queue/` — по одному markdown-файлу на материал со `status: draft`.
2. Вы открываете файл в `queue/`, меняете `status: draft` на `status: published`
   и дописываете свой абзац. Ненужные файлы просто удаляете.
3. `scripts/build_site.py` собирает HTML из всего, что помечено `published`,
   и переносит одобренные файлы из `queue/` в `posts/`.

**Без правки статуса не публикуется ничего.** Робот только приносит.

## Как одобрить материал

Открыть файл в `queue/` → карандаш (Edit) → поменять статус → Commit.
Работает и с телефона через приложение GitHub.

```markdown
---
title: Lufthansa Group launches Starlink inflight Wi-Fi
source: Aircraft Interiors International
link: https://www.aircraftinteriorsinternational.com/...
date: 2026-08-12
rubric: connectivity          # catering | entertainment | connectivity |
image: https://...            # onboard-service | cabin-seating | duty-free
status: draft                 # ← меняем на published
---

Первый абзац — краткое изложение из ленты. Он же попадёт на плитку
на главной и в подзаголовок статьи.

Второй и следующие абзацы — ваш текст. Здесь пишете, что это значит
для отрасли.
```

Робот определяет рубрику по ключевым словам и иногда ошибается — поле `rubric`
можно исправить руками.

## Что где лежит

| Путь | Назначение |
|---|---|
| `queue/` | Черновики от робота, ждут вашего решения |
| `posts/` | Опубликованные материалы, архив |
| `scripts/feeds.json` | Список лент. `enabled: false` отключает источник |
| `scripts/fetch_feeds.py` | Сбор новостей |
| `scripts/build_site.py` | Сборка HTML |
| `scripts/style.css` | Все стили сайта |
| `data/jobs.json` | Вакансии для страницы Top Jobs, правятся вручную |
| `assets/` | Логотипы, иконки, картинка для соцсетей |
| `*.html` в корне | Готовый сайт, **генерируется автоматически — руками не править** |

## Настройки

В начале `scripts/build_site.py`:

- `SITE_URL` — адрес сайта, используется в canonical и sitemap
- `NOINDEX` — пока `True`, сайт закрыт от поисковиков. Снять, когда наберётся
  достаточно материалов
- `EDITOR` — подпись под статьями

В `scripts/feeds.json`:

- `max_per_feed_per_run` — сколько материалов брать из одной ленты за прогон
- `max_age_days` — насколько старые новости ещё интересны

## Запустить вручную

Вкладка **Actions** → **Fetch feeds and rebuild site** → **Run workflow**.
Полезно, если не хочется ждать следующего часа.

## Фотографии

Изображения не копируются. Если издание отдаёт картинку в ленте, она
показывается с их сервера со ссылкой на первоисточник. Если картинки нет или
она не загрузилась, подставляется своя цветная плитка. Полные тексты и
фотографии остаются собственностью издателей — сайт публикует краткое
изложение и ссылку.
